# UPI Transactions Dashboard – Excel

## 📊 Project Overview

This project is an interactive **UPI Transactions Dashboard created entirely in Microsoft Excel**.

The dashboard provides a visual overview of transaction performance across different dimensions such as transaction amount, transaction status, UPI applications, states, banks, transaction types, cities, merchants, and gender.

The objective of this project is to transform raw transaction data into an interactive and easy-to-understand business dashboard using Excel.

---

## 🎯 Project Objectives

- Analyze overall UPI transaction performance
- Monitor transaction volume and transaction amount
- Analyze transaction success and failure rates
- Identify transaction trends over time
- Compare transaction performance across UPI apps
- Analyze transaction amounts by state and bank
- Understand transaction distribution by transaction type
- Identify potentially suspicious/fraudulent transactions
- Provide interactive filtering for better data exploration

## 📌 Dashboard Features

### KPI Metrics

The dashboard provides key performance indicators including:

- Total Transaction Amount
- Total Cashback
- Success Rate
- Suspected Fraud Transactions

### Interactive Filters

Users can filter the dashboard using:

- City
- Gender
- Merchant Name

### Visual Analysis

The dashboard includes:

- Transactions by UPI App
- Transactions by Status
- Transaction Amount by State
- Transaction Amount by Bank
- Transaction Amount by Transaction Type

## 📈 Key Analysis Areas

### Transaction Trends
Analyzes how transaction amounts change over the course of the month.

### UPI App Analysis
Compares transaction distribution across different UPI applications such as:

- PhonePe
- Google Pay
- Paytm
- Amazon Pay
- BHIM
- Cred Pay
- WhatsApp Pay

### Transaction Status
Provides an overview of:

- Successful transactions
- Failed transactions
- Pending transactions
- Refunded transactions

### State & Bank Analysis
Compares transaction amounts across different Indian states and banks to identify higher transaction activity.

### Transaction Type Analysis
Analyzes transaction amounts across categories such as:

- P2M
- P2P
- Bill Payment
- Online Shopping
- Recharge
- Subscription
- Wallet Transfer
